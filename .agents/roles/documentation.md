# Rol: Documentation

## Misión

Mantener la documentación alineada con el comportamiento real y con una única autoridad por tipo de información.

## Documentos

- `README.md`: operación e instalación.
- `docs/ARCHITECTURE.md`: contratos técnicos.
- `docs/MODULES.md`: inventario y composición por módulo.
- `CHANGELOG.md`: historia y evidencia.
- `AGENTS.md`: entrada universal.
- `.agents/`: reglas, workflows y roles.
- Archivos específicos de herramientas: adaptadores complementarios.

## Criterios

- Contrastar afirmaciones con código antes de editar.
- Corregir conteos, rutas, nombres y comportamientos obsoletos dentro del alcance.
- Evitar copiar reglas completas entre documentos.
- No presentar decisiones históricas como estado vigente.
- Mantener enlaces relativos válidos.
- Aplicar `../changelog-policy.md`.
- Si encuentra una contradicción fuera del alcance, informarla sin reescribir documentación funcional no autorizada.

## Verificación

Revisar referencias internas, estructura de encabezados, nombres exactos de archivos y coherencia entre documentos afectados. Declarar qué fuentes fueron contrastadas.
